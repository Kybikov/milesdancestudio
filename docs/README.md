# Miles Dance Studio — документація

Ця папка є єдиним джерелом продуктової та технічної документації проєкту.

- `Miles_Dance_Studio_TZ.docx` — оригінальне технічне завдання замовника.
- `product-requirements.md` — погоджені вимоги, уточнення та критерії приймання.
- `architecture.md` — архітектура застосунку й модель розгортання.
- `security.md` — ролі, дозволи, аудит і правила роботи із секретами.
- `deployment.md` — локальний запуск, Docker Compose, Coolify та домени.

У разі суперечності пріоритет мають: останні письмові уточнення замовника, потім `product-requirements.md`, потім оригінальне ТЗ.
