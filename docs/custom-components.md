# Власні компоненти Miles Dance Studio

Це перелік ключових елементів, реалізованих спеціально для робочих сценаріїв студії поверх shadcn/ui.

- **StudioCalendar** — адаптивний календар місяць/тиждень/день, часові сітки, кольори викладачів, вибір події та вільні години.
- **Subscription Kanban** — колонки життєвого циклу абонементів, залишок занять, строк і продовження без переходу на окрему форму.
- **NotificationCenter** — непрочитані системні події, нагадування за 3 дні, результати оплат і підключення Web Push.
- **ActivityDrawer** — компактна стрічка операцій користувачів без дублювання окремої сторінки.
- **ProfileMenu / Profile** — меню власниці у правому верхньому куті, персональні дані, зміна обов'язкового початкового пароля й вихід.
- **Teacher Overview** — персональні показники викладача: заняття, години, учні, власна присутність, відвідування клієнтів і прийняті платежі.
- **Client Attendance** — історія відвідувань клієнта разом зі статусом, напрямком і викладачем.
- **Owner Statistics** — фінанси, динаміка, викладачі, клієнти та окремий зріз за працівниками, які приймали платежі.

Під час приймання варто окремо переглянути календар і Kanban на вузькому телефоні, центр сповіщень, стрічку активності та обидва типи персональної статистики.
